# BD-rate 测量规则

方法依据为 [ITU-T HSTP-VID-WPOM（2020，2025 年修复交叉引用）](https://www.itu.int/dms_pub/itu-t/opb/tut/T-TUT-ASC-2020-HSTP1-PDF-E.pdf) 第 7.4 节的 BD-rate 数值计算流程。另有同主题的 [ISO/IEC TR 23002-8:2021](https://www.iso.org/standard/81591.html)。二者是说明性的测量实践技术报告，不是软件认证要求，也没有规定必须改变 preset。此处依据可公开读取的 ITU 正文实现和核查，不声称逐条验证付费 ISO 正文或完整 JVET CTC 实验流程。

## 基准方案与对比方案

BD-rate 比较 Anchor 与 Test 的两条码率—质量曲线。每条曲线固定一套编码设置，通过多个质量档位取样。编码器、版本、preset、位深或编码功能都可以是待研究因素；CRF / QP / 目标码率是取得操作点的方式，不要求两条曲线的取样参数列表或点数完全相同。仅比较两个不同 CRF 的两个成片，是两个质量点之间的比较，不能直接产生两条曲线。原视频用于给各点计算质量分数，不因自身有一个码率就成为基准曲线。

当前仅在一份打开的片段实验报告内选择基准曲线和对比曲线。报告可来自本次实验或用户主动导入的 JSON；暂不提供跨报告组合入口。长期保留需主动导出输入报告，重新导入后可复算。BD-rate 本身不另行自动保存。

## 计算定义

使用视频包平均码率 `videoMbps` 与所选指标的未舍入 `pooled` 值。每组至少 2 个采样点，建议每组 4–6 点并覆盖有用质量区间；任一组仅有 2–3 点时仍计算，但明确标注「采样稀疏，结果仅供粗略比较」。2 点时 PCHIP 退化为质量与对数码率之间的直线，3 点使用 PCHIP。原有默认实验参数保持不变；默认 3 个 CRF 在存在两个可比较组时可以计算，并显示稀疏提示。

- PSNR：直接使用 dB；沿用已有 FFmpeg 全分量 MSE 域汇总。ITU 正文第 7.3 节描述的典型口径是逐帧 PSNR-Y 的算术均值，本项目不把已有 pooled PSNR 改称该口径；两种汇总不能混作同一质量坐标。
- SSIM：先做 `Q = −10·log10(1−SSIM)` 的 dB 变换，要求 `0 ≤ SSIM < 1`。这与原始 SSIM 域积分不同，界面明确标记；不新增 SSIM 测量算法。
- VMAF：使用原始模型分数，要求各点记录同一模型。模型的输入适用性与解释沿用原报告，不把结果当作 HDR 感知质量的验证。

按质量递增排序，使用 PCHIP（分段三次 Hermite 保形插值），在质量与自然对数码率之间建曲线。内点导数使用 Fritsch–Butland 加权调和均值，端点使用单边斜率限制；分段多项式直接积分，不用离散采样近似积分。自然对数和常用对数定义经相应指数变换给出相同结果。

积分区间为两条曲线质量范围的交集 `[L,H]`：

`BD-rate (%) = 100 × [exp(∫[L,H](ln R_test(Q) − ln R_anchor(Q)) dQ / (H−L)) − 1]`

负数表示对比组在共同质量区间平均省码率；例如 −20% 表示对比组相对于基准组的平均码率比为 0.8。交换基准后为 +25%，不是 +20%。界面同时显示质量区间、该区间对每组完整质量跨度的覆盖比例和采样点数。SSIM 的区间及覆盖均在 dB 域计算。

## 可计算条件与边界

所有采样点都必须具有有限质量及正的有限码率，质量与码率均须严格递增；重复质量、相同或反向码率、缺失 / 无限指标、采样不足及没有正宽度重叠区间均明确拒算。严格递增是本软件对异常实测曲线的保守输入检查，不冒称所有 PCHIP 实现均要求码率严格递增。不会自动删除点、取包络、补造指标或外推。排序只改变计算顺序，不改变原始报告。

结果只代表共同区间和已测片段。区间很窄、点间距大、指标接近饱和或两曲线交叉时，应结合已有率失真图判断，不根据微小差异直接排名。它不能给出全片 CRF、目标码率或某个质量点的确定节省比例，也不包含音频、封装和编码速度。

BD-rate 是从当前报告实测采样点计算的派生视图，不修改报告协议或原有测量字段。计算选择与派生结果不单独写入 JSON。

## 依据与验证

BD 指标源于 G. Bjøntegaard 的 VCEG-M33（2001）；PCHIP 被用于后续 HEVC / VVC 共同测试条件。方法与使用注意参见 [FAU-LMS 参考实现及其标准文献索引](https://github.com/FAU-LMS/bjontegaard)、[The Bjøntegaard Bible（IEEE TIP 研究）](https://arxiv.org/abs/2304.12852)；PCHIP 导数定义见 [SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)。本软件实现该方法，不声称获得标准组织认证。

数学用例包含恒等、比例缩放、交换方向、2 / 3 点及混合点数、稀疏提示、非均匀取样、局部重叠、端点斜率限制及无效输入。非线性参考答案由独立 SciPy 1.17.1 `PchipInterpolator.integrate` 求得，包含 FAU-LMS 示例数据和 ITU 正文表 1。后者用印刷表格已舍入的数据复算，在 `37.54–40.19 dB` 上得到约 `−37.47148439%`，不冒称 ITU 原文给出了该最终数值。

浏览器用例使用真实 FFmpeg 编码和三种实测质量指标，核对同一报告内的曲线比较、基准互换、主动 JSON 导出与导入，以及 2 / 3 / 4 点显示、单点拒算和队列报告来源。覆盖映射见 `testing-tools/coverage.json`。
