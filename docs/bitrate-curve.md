# 音视频区间平均码率曲线

本规则仅用于完整分析中的视频与音轨码率曲线。计算前选择 100 ms 或 1 秒；100 ms 结果可聚合显示为 1 秒，1 秒数据不能恢复 100 ms 细节。视频与各音轨独立选择显示窗口。

## 测量定义

- 分子是轨道解复用包的 `size` 总量，不含容器开销、独立 extradata 或网络开销；不宣称为完整基本码流大小。
- 时间依据为轨道整数 `pts`、`duration` 与有理数 `time_base`，不用十进制 `pts_time` 分桶，也不混用 DTS。
- 使用绝对 PTS 网格：100 ms 为 `[k/10,(k+1)/10)` 秒，1 秒为 `[k,k+1)` 秒；负 PTS 用数学向下取整。音视频轨道共用绝对网格，分别截短首尾。
- 统计范围是 `min(PTS)` 至 `max(PTS+duration)`。预卷与音频填充保留在包时间跨度内，不等同于有效播放时长。时间跨度内的无包窗口为零，未测量的数据不得伪装成零。
- 整包按 PTS 所在窗口归属，不把字节均匀摊到包持续时间。此规则能用于可变帧率，不依赖平均 fps，也不假设包和显示帧一一对应。
- 每点为 `8 × 区间字节数 / 实际区间秒数`；容量与码率前缀按 1000 进位；每条视频/音频曲线按整组数值自动选择 bit/s、kbit/s、Mbit/s 等单位，缩放时保持稳定。100 ms 是时间分辨率，不是码率单位，不能宣称为瞬时峰值。

## 精确聚合与不可计算

区间字节数与时间分子以整数十进制字符串保存，时间分子表示毫秒乘以时间分母。计算期间使用 BigInt；仅绘图输出转成浮点码率和秒数。100 ms 转 1 秒时合并字节数、保留首尾边界，最后计算码率。与同起点、同边界、同包归属的直接 1 秒计算等价，包括截短尾部；不得平均舍入后的速率。

若有缺失 PTS、未知或非正持续时间、无效包大小、无效 time_base，则整个轨道曲线标为不可计算，并保存原因；本版不推断缺失时间。这一保守规则避免遗漏包后输出看似完整的曲线。超过一百万个窗口时同样明确不可计算，防止异常跨度耗尽资源。未知 duration 不能补成零来确定终点。

旧报告没有 `bitrateCurve`，仍使用旧 `bins`，不重新标记为新规则。`averageMbps`、旧 `bins/windowStats` 是保留的既有独立统计，不代表新曲线；新曲线由 `bitrateCurve` 单独承载。试编码、两文件体积比较不启用新曲线算法。

## 依据及限制

[ETSI TR 101 290 V1.4.1 §5.3.3](https://www.etsi.org/deliver/etsi_tr/101200_101299/101290/01.04.01_60/tr_101290v010401p.pdf) 根据用途定义测量窗口并允许自定义参数；MGB2 是 100 ms 更新、1 秒平均，不是本项目的 100 ms 平均。该指南针对 DVB 传输流，本项目按 PTS 统计文件包负载，不声称直接符合其某个测量配置。

[FFmpeg AVPacket](https://ffmpeg.org/doxygen/trunk/structAVPacket.html) 定义整数 PTS、DTS、持续时间及包负载；持续时间 0 可表示未知。项目采用上述字段语义，并通过字节守恒、边界测试及两种窗口计算等价性验证自己的测量规则。

## 关键测量证据留存

真实媒体等价性测试每次写出 `test-work/bitrate-equivalence-XXXXXX/measured-equivalence.json`，包含输入 SHA-256、相关源码 SHA-256、探测数据、执行命令、两种窗口完整结果、精确聚合区间、逐区间比对和字节守恒结论。记录在断言前写入；失败数据也保留。正式测试入口 `npm test` 会将它纳入既有 `measurements.json.gz` 归档，直接 `node --test` 则仅写入 test-work，不等同于永久归档。

需要单独保留关键验证时，运行 `node scripts/verify-bitrate-equivalence.mjs [媒体路径]`。默认使用现有真实编码的多音轨测试样本；这是 FFmpeg 生成的测试媒体，不是摄像机实拍。该入口重新执行测量，将输入媒体副本、逐包探测数据、完整比对、工具版本、时间和日志作为 Custom 记录，通过项目现有锁、校验和与独立记录发布机制归档。不声称完整回归通过，也不构建新版本。可用 `scripts/verify-test-evidence.ps1 -Record <记录路径>` 验证归档完整性。

补充验证使用 `node scripts/verify-bitrate-equivalence.mjs --suite`：生成低分辨率 60 秒/120 fps 和非均匀 PTS 的真实编码样本，另从实测包信息注入缺 PTS、未知持续时间故障。故障注入不冒称实拍或损坏媒体。测量数据写出后删除对应临时视频，归档保留生成命令、输入大小及 SHA-256、逐包数据和完整计算比对（gzip）、简短结果、工具/源码指纹及校验和。最小复现材料为计算模块快照与重放脚本，不复制项目、依赖或浏览器缓存。归档后运行 `node <记录>/replay/replay.mjs <记录>` 可从保存的包数据重算并核对；它不依赖当前源码或 FFmpeg，不宣称重新解码媒体，也不能仅凭输入哈希恢复原视频。成功发布并校验归档后才清理本次所属暂存目录；失败记录保留诊断。

`scripts/test-evidence.mjs` 的 `criticalMeasurements` 是关键证据清单。正式测试入口在对应测试通过后强制检查其测量文件存在且结论通过；缺失时不能把归档当作成功完成。本次先覆盖码率等价性，未宣称其他关键测试已全部纳入此门槛。
