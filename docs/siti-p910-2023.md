# SI/TI 计算依据

采用 [ITU-T P.910（10/2023）§7.8](https://www.itu.int/rec/T-REC-P.910-202310-S/en) 的内容复杂度处理流程，以 [VQEG 推荐的 siti-tools](https://vqeg.github.io/software-tools/quality%20analysis/siti/) 为公开数值参考。只保留 PQ 域流程，不再运行旧 FFmpeg 编码值域、原文倍率解释或软件自定义物理光／Alpha 合成流程。

参考源码固定为 [VQEG/siti-tools c537e33793266187aad87c859fd62a9de9033854](https://github.com/VQEG/siti-tools/blob/c537e33793266187aad87c859fd62a9de9033854/src/siti_tools/siti.py)，SHA-256 为 `84557e030e302fa14e28a1cd1227f3320986050c4cf5f5f4d590215971329873`。新报告保存这一版本、输入依据、显示参数和实际执行设备。VQEG 是公开参考项目，参考一致性不等于 ITU 官方认证；不把项目参数称为标准强制要求。

HLG 前处理修正为 P.910 附录 B.2 指定的 [BT.2100-2 表 5](https://www.itu.int/dms_pubrec/itu-r/rec/bt/R-REC-BT.2100-2-201807-S!!PDF-E.pdf)，不再沿用该固定 VQEG 版本的 HLG 高段减号及输出侧仿射黑位映射。新 HLG 结果使用 `P910-HLG-BT2100-2-PQ-v1`、配置版本 6；旧 HLG 报告保留版本 5、原值与原模型，并标注历史口径。非 HLG 计算仍使用原配置版本 5。

## 固定计算步骤

1. FFmpeg 软件解码原尺寸画面，禁止自动色彩转换、旋转、缩放和抽帧；读取明确的格式、范围及传递函数。声明缺失时需用户核实后确认。
2. YUV／灰度读取原生亮度；RGB 按明确的 BT.601、BT.709 或 BT.2020 非恒定亮度权重导出非线性亮度，不先量化到整数 Y。
3. 全范围归一化到 0–1；有限范围以输入位深的合法亮度端点归一化：`16×2^(b−8)` 至 `235×2^(b−8)`。超出声明范围则拒绝该项 SI/TI，不猜测范围或裁剪数据。
4. SDR 使用 VQEG 的 BT.1886 或逆 sRGB 显示模型，默认黑位 0.1、峰值 300 cd/m²，再编码 PQ；HLG 使用 BT.2100-2 表 5 的输入侧 β 黑位抬升、逆 OETF 和 OOTF，默认黑位 0.01、峰值 1000 cd/m²。gamma 在 400–2000 cd/m² 按注释 5f 推导，范围外采用其脚注 2 的扩展公式；PQ 输入归一化后保持 PQ。
5. SI 为 Sobel 梯度幅值的总体标准差，排除一像素边界；TI 为相邻帧亮度差的总体标准差。两者均按参考实现固定乘 255，保留未舍入数值。
6. 场景首帧 TI 未定义，保存为 null，不纳入汇总。确认多场景时逐场景统计并排除跨场景差分；未确认边界时明确标注全片参考。推荐的场景均值与辅助 P95／最大值分别展示。

SDR 保留固定 VQEG 的显示模型（300 / 0.1 cd/m²）；归一化幂函数后的黑位映射不能直接等同于使用实际黑白位的完整 BT.1886 EOTF，P.910 附录 B.2 推荐黑位为 0.01 cd/m²。有限范围采用原位深标称端点，输出固定乘 255，与标准原文的部分写法存在差异。执行优化保留这些计算约定，不宣称已消除所有标准对应差异。P.910 建议有剪辑点时按场景处理，也允许无法分离等情况下跨场景计算；未确认边界的全片结果须按此限制解释。

旧报告保留原口径、原值并标注“历史计算口径”；旧任务中的倍率、浮点等效位深或合成设置须重新选择，不能静默改算。

## 格式与执行方式

支持 8／9／10／12／14／16-bit 的已识别整数 YUV／灰度／RGB 布局，包含常见平面、大小端、半平面 NV／P0xx／P2xx／P4xx、RGB／BGR／GBR 及完全不透明的 Alpha。格式描述集中于 `public/siti.js`。

VQEG 原始输入范围表直接列出 8／10／12-bit；9／14／16-bit 使用标准整数码值关系扩展端点。RGB 权重与存储布局适配属于本软件的输入支持，参考函数负责统一的亮度后续流程，不能声称 VQEG 上游直接测试了每一种容器或布局。

浮点亮度、半透明内容、未知布局、未知传递函数、冲突且未确认的 RGB 矩阵等缺少依据时，SI/TI 返回明确的不可计算原因，其他媒体分析继续。隔行输入须明确选择 BWDIF 每帧输出一帧；滤镜不支持原生格式时拒绝该项，不偷偷转格式。

有限范围外样本当前一律拒绝，这是软件输入策略，不是标准要求所有样本只在标称黑白区间内；正常有损编码也可能触发。此类输入错误还存在解码管道收尾可能停滞的已知问题。

CPU 串行／并行及 GPU 共用输入解释、样本布局、显示参数和双精度计算模型。整数 YUV／灰度用同一函数生成 PQ 查表：CPU 逐样本查表，GPU 接收原生帧并查同一张双精度表。RGB 也直接传送原生帧，由 GPU 按共享配置给出的亮度权重、范围端点、显示参数和传递函数常数计算双精度 PQ，再计算指标；不再传送整幅主机 Float64 PQ 平面。GPU 数学后端按独立参考及 CPU 验证，不新增计算口径、不插值、不量化。Sobel、帧差和两遍总体方差仍为 fp64；场景首帧跳过无定义的 TI 统计。

CPU 串行与并行均只执行一次 SI/TI 软件解码。并行按小块连续帧轮流分发：亮度输入每块 8 帧；RGB 根据帧数与工作进程数均衡分配，每块最多 16 帧。每块额外携带准确的前一帧用于 TI，块内复用已完成的前处理。队列按工作进程数限制内存，避免逐帧配对重复 RGB 传递函数计算；保持 TI 与串行完全一致，不重新计算上一帧 SI，也不从头反复解码分段前缀。去隔行在这条完整解码流中执行，保留邻帧上下文；核对完整帧数、顺序及源 PTS。工作进程执行故障可回退串行；明确的共同输入、解码或一致性错误不重复计算。输入解码线程在 `-i` 前明确设置，rawvideo 输出线程独立固定为 1；CPU 工作进程数与解码线程数分别记录。

GPU 需要 Windows 和支持 fp64 的 OpenCL GPU。首次使用按 C# 源码哈希编译临时可执行程序，同一应用进程复用一个 GPU 工作进程、OpenCL 上下文和可复用缓冲；每次设置实际输入仍执行数值自检。空闲 60 秒或应用退出时释放工作进程；没有系统常驻服务或新增安装组件。启动前检查可执行缓存，丢失后自动重建；Windows 权限或锁冲突妨碍稳定文件名发布时，可复用已成功编译的本进程临时文件。运行代码更新后须重新启动应用。

仅设备初始化、后端计算或设备资源故障回退相同配置的 CPU；共同的输入、解码、时间戳或帧数错误直接结束该项 SI/TI，其他媒体分析继续。取消不回退。报告保存每次尝试的设备、帧数、失败阶段、原因和耗时；GPU 上传／计算／回读计时与输入等待分别记录，输入等待与解码有重叠，不能相加推算总耗时。界面允许重新检查 GPU，不永久禁用选择。

HLG 新计算拒绝 β≥1 的反向或恒定映射参数组合；只约束模型有效域，不指定新的显示黑位默认值。历史报告仍按原参数、原值验证并保留，不重新运行。确认单场景时顶层统计复用场景统计。P.910 未规定本项目的进程结构、精度类型、速度、资源预算或工程误差容限；本次执行优化不消除前述 SDR、范围和输出尺度的已知对应差异，也不宣称无条件完整符合所有标准表述。

运行代码只有四个文件：`siti.mjs`（解码／调度／工作进程）、`public/siti.js`（输入／计算／验证）、`gpu/SitiOpenCl.cs`（GPU 指标）、`gpu/siti-opencl.ps1`（系统桥接）。无需 Python 运行依赖。

## 数值验证

测试仅保留一份固定参考源码、一份参考矩阵和一个生成脚本。`scripts/generate-siti-reference.py` 使用未修改的 VQEG 归一化、非 HLG 显示模型、PQ、SI、TI 和输出尺度函数，以及独立转录的 BT.2100-2 表 5 HLG 公式生成 84 组向量；不会用生产代码生成预期值。原始 VQEG HLG 函数只生成历史报告验证样例。新增 HLG 边界、RGB、显示峰值及黑位对照，检查连续性、单调性和 CPU/GPU 一致性。NumPy／SciPy 只用于开发期重新生成参考矩阵。

CPU／GPU 核对真实解码画面、整数位深、范围、SDR／HDR、RGB、场景及去隔行；GPU 原生帧通道直接核对全部 84 组亮度与 RGB 参考向量，含 P010、大小端、填充位、合法范围及 Alpha，检查截断输入、跨格式上下文复用、缓存重建、共同校验错误不回退和取消恢复；CPU 核对 VFR、准确前帧、一次解码、AVC／HEVC／AV1 和取消。API、报告及浏览器核对设置与数据往返。误差阈值 `1e-8 + 1e-10×|参考值|` 是工程验收阈值，不是 ITU 容限。不能可靠标记部分布局的原始 NUT 文件不作为真实解码证据。

SI/TI 描述内容复杂度，不是质量评分或剩余压缩率。比较仍须相同的显示假设、分辨率、帧率、场景及前处理条件。
