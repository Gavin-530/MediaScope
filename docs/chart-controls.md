# 图表范围与显示

共用分析图表的横轴和纵轴范围独立。横轴放大、平移、定位、全览及双击全览不解除纵轴锁定。

纵轴提供三种模式：

- **自动**：按当前绘制的全部曲线确定范围，横向缩放时保持；切换曲线数据后重新计算。
- **随 X 缩放**：按当前横轴区间内的数据重算范围，区间量包括与视口相交的完整测量区间。
- **锁定**：选择时冻结当前显示范围，并展开 Y 下限和上限；修改后点击“应用”，精确使用这两个边界。上限不为容纳极端值自动扩大，下限也不强制归零。空值、非有限数、上下限相等、倒置及跨度溢出时拒绝应用，保留此前有效范围。切回“自动”即恢复全数据自动范围。

横纵轴控件共用一条可换行工具栏，均通过模式选择显示手动输入。X 轴默认“自动”，起止输入收起，初始视口由当前图表决定；选择“自定义”时显示当前起止范围，修改后点击“应用”，输入区保持展开。切回“自动”恢复横轴全览并收起输入。放大、缩小、平移和全览在两种模式下均可直接使用；横向浏览不改变已选模式。Y 轴自动模式不显示手动边界输入。提示区仅在下限非零、数据超界或输入无效时显示说明。

坐标类型或指标选择放在对应轴的范围设置旁。帧大小图的时间／帧序号、码率—质量图的横纵轴指标、逐帧质量图的纵轴指标共用这一布局；只有实际提供选择的图表显示相应控件。全片查看统一使用工具栏的“全览”；帧大小图的全览、双击全览和切回 X 轴自动均解除所选 GOP 的局部查看，后续切换坐标类型继续显示全片。无可绘制数据时保留坐标或指标选择，便于切回可用视图。

切换帧大小图的时间／帧序号坐标使用相同绘图区尺寸，坐标选择框保持相同宽度；绘图缓冲区按实际显示尺寸与屏幕像素比例建立，不因绘图类型改变高度或拉伸显示。切换时保留 X 轴输入区的展开状态，起止值随新坐标视图同步。键盘焦点在坐标选择框上时，切换后保留焦点，不主动滚动页面。

同一报告、同一图表中的每种纵轴指标分别保留视图状态。筛选曲线、切换同一指标的对比组以及暂时取消全部曲线后恢复时，已锁定范围继续生效。切换为不同指标使用该指标自己的状态；返回原指标时恢复原范围。码率窗口切换引起单位前缀变化时，锁定边界按基础单位换算，保持同一物理范围。重新打开或导入报告创建新的图表，不继承另一报告的范围。

数据只在绘图区内裁剪显示，不把超界值改成边界值。当前横轴区间有有限数据超出 Y 范围时，界面分别提示上方、下方超界项数；分组数据按绘图项计数，不冒充原始帧数。非零下限明确提示。原始数据、统计、悬停证据及 CSV/JSON 导出不因视图裁剪改变；视图状态不写入测量报告，也不跨应用会话保存。

坐标范围与测量值的合法范围分开。手动范围允许负边界，用于留白或固定比较尺度；这不表示包大小等非负量可以测出负值，也不把原始分数截成零。各类数据的口径如下：

| 数据 | 负值的含义 |
| --- | --- |
| 包大小、码率、SI/TI、耗时、编码速度 | 测量值非负；负刻度只属于显示范围 |
| 原始 SSIM | 可以为负，保留上游结果及对应负区间；依据 [FFmpeg SSIM 实现](https://github.com/FFmpeg/FFmpeg/blob/master/libavfilter/vf_ssim.c)的协方差项 |
| PSNR | 当前 FFmpeg 支持的原生有界整数样本，按峰值与 MSE 的公式推得非负；完全相同为正无穷。公式见 [FFmpeg PSNR 实现](https://github.com/FFmpeg/FFmpeg/blob/master/libavfilter/vf_psnr.c) |
| 当前三个 VMAF 模型 | 保留模型默认 0–100 裁剪；NEG 表示不奖励增强处理，不表示负分。见 [官方模型说明](https://github.com/Netflix/vmaf/blob/v3.0.0/resource/doc/models.md)及 [NEG 模型的 score_clip](https://github.com/Netflix/vmaf/blob/v3.0.0/model/vmaf_v0.6.1neg.json) |
| BD-rate 结果 | 可以为负，表示对比方案相对基准节省码率；当前显示在结果表，图中纵轴仍是所选质量指标 |
| 原始时间戳 | 可以为负，按源时间证据保留；不是负的字节数、计数或质量分数 |

柱形和竖线的测量基线始终是数据零点，随后按视图范围裁剪；不能把手动下限当作基线。零值柱不强制填成正高度。当包大小图显示负刻度时，零线以下保留为空白；当视口完全低于零时，正数柱线不应出现。折线、散点和区间线按实际值定位，不引入柱形基线。

计数图只绘制整数主刻度，手动边界仍允许小数；连续量保留小数刻度。刻度数量和间隔用于排版，不是测量阈值。自动上限可扩展到整刻度，手动边界不因刻度调整。依据 [Chart.js 对显式 min/max 与自动范围的区分](https://www.chartjs.org/docs/latest/axes/)，使用现有绘图组件和浏览器原生裁剪，不新增绘图库依赖。
